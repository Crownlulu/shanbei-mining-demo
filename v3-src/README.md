# v3 源码（员工填报端原型）

技术栈：Vite + React 18 + Ant Design 5。线上访问的是仓库根目录下已构建好的 `v3/` 文件夹。

```bash
cd v3-src
npm install          # 第一次需要
npm run dev          # 本地预览
npx vite build       # 生成 dist/
rm -rf ../v3 && cp -r dist ../v3
```

- `src/data.js`：演示数据、填写说明、字段帮助（政策依据均为示例）
- `src/checks.js`：智能检查规则（含破格依据、与单位关系、证书编号、学时、附件）
- `src/status.js`：统一的状态文字和颜色
- `src/pages/`：工作台、申报表、提交前检查、申报记录、政策文件

## 演示路线（约 5 分钟）
1. 工作台：条件自查显示继续教育学时不足
2. 申报表 → 申报信息：点“申报方式”的问号；切到“破格申报”并选一个依据，系统提示依据不成立，再切回正常申报
3. 逐项修正：证书编号、2025 学时、上传聘任文件、补获奖排名、业绩加数字
4. 提交前检查 → 勾选承诺 → 提交
5. 申报记录 → “模拟退回修改”→ 工作台出现退回提醒 → 重新上传业绩证明 → 重新提交
6. “模拟审核通过”，查看完整审批记录
